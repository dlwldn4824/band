## 다시 만들어야 합니다

**이 두 이미지는 BANDY 시절 자료입니다.** 제목에 BANDY가 박혀 있고 화면 캡처도 예전 버전이라, 지금 사업계획서에 그대로 넣을 수 없습니다. 서비스명이 **마주(MAJU)** 로 바뀌었으므로 현재 화면으로 다시 생성해야 합니다.

다시 만들 때 맞춰야 할 것:

- 제목·워드마크의 BANDY → **마주 (MAJU)**
- 화면 캡처를 현재 버전으로 교체 — 특히 새 소개 페이지(`/intro`), 탐색(`/explore`), 동아리 프로필(`/clubs/:clubId`), 행사 상세(`/shows/:eventId`), 내 마주(`/my`), 운영진 콘솔(`/club-console`), 현장 프로필 교환(`/card/:shareCode`)
- 디자인 원칙 유지 — 검정 배경, 흰 텍스트, `#2a2a2a` 카드, 포인트 `#ff4c4c`, 제목 HakgyoansimJayeonR / 본문 Pretendard
- 화면에 보이는 대학·동아리·공연장 이름은 전부 **가상 더미 값**으로 (실제 단체·장소 이름을 넣지 않습니다)
- 1920×1080 규격 유지, 내보내기는 2배 해상도

파일명의 `bandy` 는 **그대로 둡니다.** 브랜드명만 바뀌었고 코드·자료의 식별자는 유지하는 저장소 방침과 같습니다 (최상위 [`README.md`](../../README.md) 참고). 교체하기 전까지 기존 파일은 지우지 말고 남겨 둡니다.
