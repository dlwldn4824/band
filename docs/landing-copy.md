## 7. 예약 폼 — 유입 경로가 남는 자리

> **예약 한 번에, 필요한 게 다 남습니다.**

누가 몇 명 오는지, 그리고 **어느 동아리를 거쳐 왔는지**까지 예약 시점에 기록됩니다.
공연이 끝나고 "홍보가 잘 됐나?"를 추측하지 않아도 됩니다.

| 질문 | 예시 답변 |
|---|---|
| 이름 | 박지우 |
| 연락처 | 010-1234-5678 |
| 몇 명이 오나요? | 2명 |
| **어느 동아리를 통해 알게 되었나요?** | **블랙노트 공연 보러 갔다가요** ← 초록 강조 |

> 마지막 한 줄이 우리 핵심 지표가 생기는 지점입니다. 이 질문만 색을 다르게 줍니다.

## 8. 기능 3연속

### 8-1. 예약자 전원이 같은 화면으로

공연 당일, 예약한 사람들이 티켓·셋리스트·채팅·방명록이 있는 화면으로 들어옵니다.
**아래는 실제 공연에 쓰인 화면입니다.**

폰 4칸: `티켓·입장번호` `셋리스트` `실시간 채팅` `방명록` · 버튼 `행사 둘러보기`

> 페이지에서 **유일하게 실제 캡처를 쓰는 자리**입니다. "진짜 돌아간다"는 증거가 한 군데는 필요합니다.

### 8-2. 이 관객이 어디서 왔는지, **증명할 수 있습니다**

교류를 거쳐 들어온 예약에는 표시가 남습니다. 그래서 "홍보를 열심히 했다"가 아니라
"기존 인맥 밖에서 몇 명이 왔다"로 말할 수 있습니다. 티켓만 파는 서비스는 이걸 구분하지 못합니다.

연출: **배지가 차례로 켜지며 비율이 올라감** → **60% 교류로 유입된 관객**

| 예약자 | 인원 | 교류 유입 |
|---|---|---|
| 김민서 | 2명 | ✅ |
| 이준호 | 1명 | |
| 박서연 | 3명 | ✅ |
| 정하윤 | 2명 | ✅ |
| 최도윤 | 1명 | |

버튼: `운영진 콘솔 보기`

### 8-3. 현장에서 끝나지 않게

행사장에서 NFC·QR·링크로 프로필을 교환합니다. 공개할 연락 수단은 본인이 고릅니다.
교환한 사람은 목록에 남아 다음 행사 참여로 이어집니다.

연출: **카드 두 장이 맞닿아 서로의 연락처가 열림**

- 지우 · 소리풀 · 한빛대 — `#밴드` `#작곡` → 받은 것 `@minseo_dr`
- 민서 · 블랙노트 · 새길대 — `#밴드` `#드럼` → 받은 것 `@jiwoo_gtr`

캡션: 공개로 둔 항목만 상대에게 전달됩니다. 연락처를 닫아 두면 교환해도 보이지 않습니다.
버튼: `내 프로필 만들기`

## 10. 기능 요약 (4줄)

- 링크 하나로 예약. 앱 설치도, 회원가입도 없습니다.
- 정원·잔여석 자동 관리. 중복 예약과 초과 예약을 서버가 막습니다.
- 공개 범위는 본인이. 연락처와 인스타는 동의한 항목만 상대에게 갑니다.
- 운영진 코드로 관리. 교류 수락과 방문 확인을 동아리가 직접 합니다.

## 11. 지표

> **기능이 아니라 숫자로 봅니다.**

파일럿에서 아래 네 가지를 측정합니다. 이용량이 아니라, 연결이 실제 관객 유입으로
이어지는지가 기준입니다.

| 값 | 지표 |
|---|---|
| 83% | 교류 요청 수락률 |
| 50% | 교류로 유입된 관객 비율 |
| 33% | 예약 대비 실제 방문율 |
| 8곳 | 파일럿 참여 동아리 |

단서: 파일럿 환경에서 측정한 값이며, 운영 규모에 따라 달라집니다.

> ⚠️ 지금은 **하드코딩**입니다. `/api/club-events` 의 `stats` 액션이 같은 값을 계산하므로,
> 실데이터가 쌓이면 그대로 물려서 실시간 수치로 바꿀 수 있습니다.

## 작성 원칙

**넣는 것**
- 우리만 할 수 있는 주장 (교류 → 유입 → 증명)
- 실제로 돌아간다는 증거 한 군데
- 숫자

**빼는 것**
- 검색·필터·로그인 같은 당연한 기능 — 자랑거리가 아닙니다
- 없는 신뢰도 (언론 로고 자리를 분야 띠로 바꾼 이유)
- 섹션당 두 개 이상의 움직임

**움직임은 섹션당 하나씩, 서로 다르게**

| 섹션 | 동작 |
|---|---|
| 히어로 | 연결됨 |
| 탐색 | 교체됨 |
| 유입 지표 | 순차 점등 |
| 현장 교환 | 맞닿음 |

전부 **화면에 들어온 순간부터** 시작합니다. 화면 밖에서 돌면 스크롤해 도착했을 때
이미 중간이라 처음을 놓칩니다.

## 13. 피그마와 코드 차이

현재 [피그마 파일](https://www.figma.com/design/mLwN6nNV8jjSE70CiWRhvs)과 코드가 어긋난 지점입니다.

| 항목 | 피그마 | 코드 | 해야 할 일 |
|---|---|---|---|
| 서비스명 | 마주 / MAJU | **밴디 / BANDY** | 피그마를 밴디로 |
| 히어로 | "마주 앉는 곳" | "한자리에 모이는 곳" | 피그마 문구 교체 |
| 마무리 | "누구와 마주 앉을까요?" | "누구와 만나볼까요?" | 피그마 문구 교체 |
| 분야 | IT·개발 **있음** | **없음** | 코드에 추가할지 결정 |
| 행사 카드 | 해커톤·데모데이 **있음** | **없음** | 위와 같이 결정 |
| 이모지 | 선 아이콘으로 교체됨 | 이모지 | 아이콘으로 갈지 결정 |

**IT·개발 분야는 넣는 쪽을 권합니다.** "모든 도메인에 쓸 수 있어야 한다"는 방향과 맞고,
해커톤·데모데이가 들어가면 공연 전용 서비스로 보이지 않습니다.
코드에서는 `src/types/bandy.ts` 의 `CLUB_CATEGORIES` 에 한 줄,
서버 `server/lib/bandyCore.js` 의 같은 목록에 한 줄을 더하면 됩니다.
